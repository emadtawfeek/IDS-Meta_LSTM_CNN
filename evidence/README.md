# Lightweight reproduction evidence

This directory contains small, text-based artifacts generated from saved evaluation
arrays and published confusion matrices:

- `paper-recalculation/`: independently recalculated paper metrics and the
  submitted-versus-paper comparison.
- `submitted-cic-binary-audit/`: the independently reproduced submitted confusion
  matrix, classification report, metrics, and source-artifact hashes.

Raw datasets, prepared arrays, fitted preprocessors, predictions, probabilities,
and trained models are intentionally not committed. Recreate them with the commands
in the project README.
